# jarVisXstar

Perpustakaan keamanan web yang dirancang untuk melindungi website dari serangan siber modern.

## Fitur
- WAF Engine (deteksi SQLi, XSS, RCE, Log4J, SSTI, GraphQL, dll)
- Multi-layer obfuscation bypass
- Behavioral analysis (scanning, brute force, slow attack)
- Adaptive threshold
- Active honeypot
- JWT Guard dengan Redis
- Dynamic rate limiter
- Middleware untuk Flask, Django, FastAPI
- CLI scanner
